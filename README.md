# Frontend Practice

HTML, CSS and JavaScript practice projects, built without frameworks.

**Live site:** https://emmanueldev9.github.io/Frontend-Practice/

## ZONAR Studios

A unisex fashion store with product sliders for menswear, womenswear and watches.

- Product image sliders
- Shopping cart
- Favourites
- Customer reviews
- Newsletter sign-up

The cart, favourites and reviews are saved in the browser with `localStorage`, so they are still there after a refresh.

Built with HTML, CSS and JavaScript.

## Aura Motion

A branding and web agency site with home, services and portfolio pages. This project is still in progress, so its portfolio images and client reviews are placeholders.

## Run it locally

Download the repo, then open `zonar-studios/index.html` in your browser.
